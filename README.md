# Magic Mirror Maze

Three children, three mirrors, one beam of light.

Each child turns their own mirror. Together they guide the beam through a courtyard and into the treasure chest. The full design is in [Magic_Mirror_Maze_Game_Description.md](Magic_Mirror_Maze_Game_Description.md). Level 1, The First Spark, is shown in the concept picture.

This game is desktop-only. The camera, tracking, and window all run on one computer.
