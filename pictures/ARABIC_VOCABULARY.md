# Arabic picture vocabulary: 100 starter words

This is the artwork list for future expansion. The current live tutor starts with the six pictured words already included in the game; the rest below still need to be added to its lesson data and supplied with artwork. Please use the exact filename in the last column for each image. Existing six images may also be replaced.

For the image generator: create one recognizable object per image, centered and large, in a cheerful, colorful storybook style suitable for children aged 5–10. Use a square 1024×1024 PNG, a simple uncluttered background, no text, letters, labels, watermarks, or extra objects. Save each image as `assets/vocab_<filename>.png`.

Arabic grammatical gender matters: **m** uses ما هذا؟ / هذا, while **f** uses ما هذه؟ / هذه. Pronunciations below are approximate English spellings; the Arabic spelling is the reference.
